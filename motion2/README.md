# Ролик «2ГИС → лендинг»

Продающий ролик 57,5 секунд: скрипт, живая озвучка, моушен-дизайн, саунддизайн,
реальные лендинги из портфолио внутри кадра.

## Файлы

| Файл | Что это |
|---|---|
| `out/lendings-2gis-57s.mp4` | основная версия — 1920×1080, 60 fps, 38 МБ |
| `out/lendings-2gis-57s-light.mp4` | облегчённая для мессенджеров — 13 МБ |
| `out/FINAL.jpg` | контрольный лист кадров |
| `src/index.tsx` | вся анимация (Remotion) |
| `src/timeline_v4.json` | таймлайн, посчитанный по реальной длине озвучки |
| `make_voice4.py` | синтез голоса + правка под него |
| `voice_engine.py` | низкоуровневый движок Edge TTS (SSML, подрезка тишины) |
| `build_mix.py` | микс: голос + музыка + саунддизайн с авто-дакингом |
| `get_sfx.py` | скачивание музыки и SFX (Freesound, CC0) |
| `public/*.png` | полностраничные скриншоты реальных лендингов |

## Голос

**Piper (VITS), полностью офлайн.** Модели `ru_RU-{ruslan,denis,dmitri,irina}-medium`
скачиваются с HuggingFace. Интернет и облачные сервисы не нужны.

Почему Piper, а не Edge TTS — измерил объективно (разброс высоты тона, вариативность
энергии, доля тишины):

| Голос | Разброс тона | Разброс энергии | Тишина | Балл |
|---|---|---|---|---|
| **ruslan (Piper)** | **96 Гц** | 0,078 | 4,6 % | **105** |
| denis (Piper) | 43 Гц | 0,095 | 7,1 % | 54 |
| Edge DmitryNeural | 40 Гц | 0,061 | 6,7 % | 46 |

Разброс тона — это интонационная выразительность. У ruslan он в 2,4 раза выше,
чем у Edge: это и есть «живая» подача вместо ровного чтения.

Параметры Piper подкручиваются на каждый сегмент:
- `length_scale` — темп (для «+23 %» голос замедляется и становится весомее)
- `noise_scale` — вариативность тембра
- финальная нормализация по EBU R128: −16,3 dB, пик −1,5 dB

Произношение: Edge не принимает SSML-теги (`phoneme`, `break`, `express-as`),
поэтому слова с проблемным ударением пишутся орфографически:
«2ГИС» → «два ГИС», числа — прописью.

## Моушен

Три слоя глубины, всё движется постоянно:

- **камера** — непрерывный наезд 1.00 → 1.12 + дрейф;
- **средний план** — сетка едет с наклоном, три световых блума пульсируют, 44 частицы;
- **передний план** — 26 частиц крупнее, полоса света, зерно, скан-линии.

Переходы между сценами: кросс-фейд с перекрытием 20 кадров, RGB-split,
летящие световые полосы, утечка света. Сцены **наезжают друг на друга**,
а не идут одна за другой.

Ключевые приёмы:
- **морф** — карточка 2ГИС разворачивается в настоящий сайт (shared element);
- **реальные лендинги** из портфолио: скриншоты 1920×2400 скроллятся в браузере;
- сайты кружат вокруг иконки звонка и наплывают за «ЧТО МЕНЯЕТСЯ»;
- лейблер главы в углу: «КАРТОЧКА В 2ГИС» → «ССЫЛКА НА САЙТ» → «ДАННЫЕ САМОГО 2ГИС»;
- курсор кликает по кнопке, из неё вылетают искры;
- счётчик +23 % прокручивает разряды, столбики графика растут по очереди;
- бегущие строки внутри карточек, блики по кнопкам, пульсация свечения.

## Саунддизайн

34 события по таймлайну: ризеры, импакты, ктоши, клики, саб-бумы.
Музыкальный бед (CC0, Freesound) автоматически приглушается под голос
через `sidechaincompress` — как в эфире.

## Пайплайн

```bash
# 1. озвучка (пересчитывает таймлайн под фактическую длину звука)
python make_voice4.py

# 2. саунддизайн (один раз)
python get_sfx.py

# 3. микс
python build_mix.py

# 4. рендер
npx remotion render src/index.tsx Main out/video.mp4 --browser-executable="C:\Program Files (x86)\Google\Chrome\Application\chrome.exe"

# 5. финальная сборка + лимитер
ffmpeg -i out/video.mp4 -i mix_final.wav -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
  -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
  -c:a aac -b:a 192k -ar 48000 -ac 2 -shortest -movflags +faststart out/lendings-2gis-57s.mp4
```

## Правка скрипта

Текст, интонация и тайминги — в массиве `SEG` (файл `make_voice4.py`).
Поправил формулировку → `python make_voice4.py` → таймлайн пересчитается
→ `build_mix.py` → рендер. Видео соберётся заново уже под новый текст.

Если меняешь формулировки сильно — прогони `make_voice4.py` сначала, и только
потом рендери: иначе тайминг сцен разойдётся с голосом.
