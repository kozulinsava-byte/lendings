# Ролик «2ГИС → лендинг»

Продающий ролик 66,6 секунды: живая озвучка, моушен-дизайн, саунддизайн,
реальные лендинги из портфолио внутри кадра.

## Что отдать исполнителю

Папка **`assets/`** + файл **`VIDEO-BRIEF.md`** — это всё, что нужно.

| Файл | Что это |
|---|---|
| `VIDEO-BRIEF.md` | творческий бриф: как должно выглядеть и ощущаться, поминутный сценарный план, палитра, принципы движения, чек-лист приёмки |
| `assets/voice.wav` | **финальный звук**: голос + два музыкальных слоя + саунддизайн, 48 кГц |
| `assets/voice.mp3` | то же для быстрого прослушивания |
| `assets/voice_clean.wav` | только голос, без музыки и эффектов — если исполнитель собирает микс сам |
| `assets/beatmap.json` | точная карта битов: `id` / `start` / `end` / текст реплики |
| `assets/shawarma.png` | скриншот лендинга «Лава & Огонь», 1920×2400 |
| `assets/beauty.png` | «Бархат» (светлый, Playfair) |
| `assets/auto.png` | «Гараж 7» (индустриальный, жёлтый) |
| `assets/dental.png` | «Белая линия» (мятный) |
| `assets/portfolio.png` | скриншот самого портфолио |

**Тайминги не придумывать — брать из `beatmap.json`.** Озвучка собрана под эти цифры.

## Голос

**Piper (VITS), офлайн.** Модели `ru_RU-{ruslan,denis,dmitri,irina}-medium` с HuggingFace.
Интернет и облачные сервисы не нужны.

Голос выбран **по измерениям**, а не на глаз — разброс высоты тона, вариативность
энергии, доля тишины:

| Голос | Разброс тона | Разброс энергии | Тишина | Балл |
|---|---|---|---|---|
| **ruslan (Piper)** | **96 Гц** | 0,077 | 4,3 % | **106** |
| denis (Piper) | 55 Гц | 0,084 | 6,2 % | 64 |
| irina (Piper) | 34 Гц | 0,077 | 14,8 % | 41 |
| dmitri (Piper) | 29 Гц | 0,076 | 7,9 % | 37 |
| Edge TTS (было) | 40 Гц | 0,061 | 6,7 % | 46 |

Разброс тона — это интонационная выразительность. У ruslan он в 2,4 раза выше
Edge: это «живая» подача вместо ровного чтения. XTTS-v2 тоже пробовали — оказалась
плоской (разброс 26 Гц), кросс-язычный голос не тянет.

### Что было исправлено после прослушивания

Замеры показали три конкретные проблемы — и все три устранены:

| Проблема | Было | Стало |
|---|---|---|
| Речь слишком быстрая, слова слипались | **19,2 симв/с** | **16,3 симв/с** (норма 12–16) |
| Между репликами не было пауз | **0 пауз** длиннее 0,3 с | 16 пауз, 0,20–1,50 с |
| Резкие начала и концы реплик | макс. скачок **0,608** | **0,275** (мягкие fade 25/40 мс) |
| Музыки не было слышно | **−37 dB** в паузах | **−30…−34 dB**, с явным битом |
| Щелчки на стыках | — | **0** на границах битов |

Темп и длительность подбираются автокалибровкой: ролик целится в 67 секунд,
`length_scale` подбирается итеративно, потому что длина пропорциональна ему.

Параметры Piper подкручиваются на каждый сегмент (`make_voice.py`, массив `SEG`):
`length_scale` — темп (на цифре медленнее и весомее), `noise_scale` — вариативность
тембра (к финалу выше). Финальная нормализация по EBU R128: −20 dB RMS, пик −3,7 dBFS.

Произношение: Edge не принимает SSML-теги (`phoneme`, `break`, `express-as`),
поэтому слова с проблемным ударением пишутся орфографически: «2ГИС» → «два ГИС»,
числа — прописью.

## Саунддизайн

**Два музыкальных слоя** — это и есть «разнообразие»:

- **слой A** — ровный бед на весь ролик, тише в первом акте;
- **слой B** — энергичный electrohouse, входит на «переломе» (0:22,7) и держит до конца;
- между слоями — разные фильтры, разные точки входа, разные текстуры.

Плюс 35 событий поверх: ризеры (5), импакты (5), ктоши на каждой смене сцены (19),
клики на UI-моментах (4), саб-бумы (2). На всех событиях — fade, поэтому щелчков нет.

**Дакинг точный, а не на глаз:** собирается ключевой сигнал по карте битов
(900 Гц ровно в момент речи, тишина в паузах) и подаётся в `sidechaincompress`.
Замер: речь −20,5 dB, пауза с музыкой −18…−34 dB — музыка слышна, но не лезет.

## Пайплайн

```bash
# 1. озвучка (автокалибровка темпа под 67 с + паузы + мягкие края)
python make_voice.py

# 2. микс: два музыкальных слоя + саунддизайн + точный дакинг
python build_mix.py

# 3. пакет для исполнителя + перегенерация таймингов в брифе
python make_assets.py

# 4. рендер
npx remotion render src/index.tsx Main out/video.mp4 --browser-executable="C:\Program Files (x86)\Google\Chrome\Application\chrome.exe"
```

**Правка скрипта:** текст, интонация и тайминги — в массиве `SEG` файла
`make_voice.py`. Поправил формулировку → `make_voice.py` → `build_mix.py` →
`make_assets.py` → рендер. Озвучку перегенерировать перед этим **нельзя**,
иначе разъедется таймлайн.

## Скриншоты лендингов

Снимаются headless Chrome с локального сервера проекта:

```bash
cd Z:\лендинги
npx http-server -p 5173 -c-1 .
chrome --headless=new --window-size=1920,2400 --virtual-time-budget=11000 \
  --screenshot=motion2/public/shawarma.png http://127.0.0.1:5173/sites/shawarma/index.html
```

## Заметка про диск Z:

Сетевой диск периодически отваливается — если команда «не видит файл»,
это флэк диска, а не ошибка. Скрипты переживают это повторами.
