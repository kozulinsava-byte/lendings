# Текст для ElevenLabs — ролик «2ГИС → лендинг»

Формулировка сделана под три вещи сразу: **эмоция через аудиотеги**, **непрерывное
чтение без «ступенек»** (никаких пауз на стыках реплик) и **правильное
произношение без словаря** — все числа и названия написаны так, как их надо
произнести.

---

## 1. Настройки генерации

| Параметр | Значение | Почему |
|---|---|---|
| Модель | **Eleven v3 (Conversational / v3)** | только v3 понимает аудиотеги `[...]` |
| Голос | **Dmitri** (русский male) | запасные: George, Josh, Matvey, Charlie |
| Stability | **35–42** | ниже 30 — «плавает», выше 60 — монотонно |
| Clarity + Similarity | **72–80** | выше 85 — голос звучит «записанным» |
| Style Exaggeration | **20–30** | усиливает эффект аудиотегов |
| Speaker Boost | **вкл** | |
| Speed | **+8…+12%** | без этого ролик растянется за 80 с |

> Если интерфейс предлагает **«Audio Tags»** / **«V3 tag»** — включи, иначе `[...]`
> будет прочитано вслух.

## 2. ОСНОВНОЙ ТЕКСТ — копировать целиком, одним куском

```
[calm] Человек находит тебя в два ГИС, видит карточку, а дальше ему некуда идти, в карточке — адрес и телефон, но он не видит, какие услуги ты оказываешь, сколько они стоят и есть ли свободное окно, звонить он не хочет, он хочет просто посмотреть, и в итоге уходит к конкуренту, у которого в карточке есть ссылка на сайт. [dramatic] А теперь смотри, что меняется. [excited] Ты прикрепляешь к своей карточке в два ГИС нормальный сайт, человек заходит и сразу видит услуги, цены, фотографии работ, понимает, что ты серьёзная компания, которой можно доверять, и звонит уже практически готовым клиентом. [confident] По данным самого два ГИС, одна только ссылка на сайт в карточке повышает конверсию в звонок или запись почти на двадцать три процента. [serious] Я делаю такие сайты. [excited] Стоимость — восемь тысяч рублей, половина оплачивается вперёд, всё просто и красиво: услуги, цены, фотографии работ, чтобы твоя карточка в два ГИС наконец-то работала как надо. [cheerful] Хочешь посмотреть примеры? [excited] Напиши одно слово — сайт — и я скину тебе портфолио! [excited] У меня уже много довольных клиентов!
```

### Почему текст написан именно так

| Приём | Где | Зачем |
|---|---|---|
| Точки заменены запятыми | почти весь текст | **непрерывное чтение «как из пулемёта»**, нет ступенек на стыках |
| Точки остались только на 5 переломах | после «…ссылка на сайт», «…двадцать три процента», «…готовым клиентом», «…работала как надо», «…примеры?» | пауза работает как драматургическая точка, а не как случайный разрыв |
| `два ГИС` вместо `2ГИС` | 4 раза | **гарантированное произношение**: «два ГИС», а не «двэ-гис» |
| `двадцать три процента` | 1 раз | не «23 процента» и не «двадцати-три» |
| `восемь тысяч рублей` | 1 раз | не «8 000 ₽» — валюту он прочитает как «восемь ноль-ноль-ноль» |
| `одно слово — сайт` | 1 раз | без кавычек: 11Labs не всегда читает текст в кавычках как слово |
| `работала`, а не `работало` | 1 раз | грамматика — «карточка работала» |
| Тире `—` | 3 раза | пауза внутри фразы, но без «ступеньки» на границе реплик |

### Драматургия тегов

| Тег | Смысл | Где стоит |
|---|---|---|
| `[calm]` | холодно, пусто, ровно | начало, «человек не видит услуг» |
| `[dramatic]` | резкий перелом | «А теперь смотри, что меняется» |
| `[excited]` | энергия, движение | блок решения, цена, финал |
| `[confident]` | уверенная подача факта | «двадцать три процента» |
| `[serious]` | вес, спокойная уверенность | «Я делаю такие сайты» |
| `[cheerful]` | тёплый вопрос | «Хочешь посмотреть примеры?» |

Если v3 не знает тег — он всё равно отработает, просто без эффекта. Критичны
`[excited]` и `[calm]`, остальные украшение.

## 3. СЛОВАРЬ ПРОИЗНОШЕНИЯ (если хочешь писать в тексте «2ГИС»)

ElevenLabs → **Speech Settings → Add pronunciation**:

| Alias (что пишешь) | Phonetic / замена (как читать) |
|---|---|
| `2ГИС` | `два ГИС` |
| `8 000 ₽` | `восемь тысяч рублей` |
| `23 %` | `двадцать три процента` |

С этими записями можно писать в тексте `2ГИС` и `23 %` — и слышно будет правильно.
Основной текст выше словаря не требует, но словарь полезен, если будешь
переписывать реплики.
