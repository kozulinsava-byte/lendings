# Вкусовой атлас

Статический сайт-исследование о сочетаниях продуктов: 173 ингредиента, 3 801 связь,
генератор сочетаний на 2–4 компонента и 69 курированных трио.

Живая версия: <https://kozulinsava-byte.github.io/lendings/flavor/>

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | герой-созвездие, генератор, категории, трио дня, метод |
| `atlas.html` | все 173 ингредиента, фильтры по категории, цене и сезону, сортировки |
| `ingredient.html?id=…` | карточка: профиль по 7 осям, сезон, цена, все связи по силе, трио и похожие профили |
| `combos.html` | 69 готовых трио с фильтрами и кнопкой «Собрать трио» |
| `method.html` | принципы, коды причин, ограничения и источники |

Сборки нет: открывается как есть, в том числе с GitHub Pages.

## Данные

Все данные — обычные JS-файлы в `assets/data/`, подключаются до `app.js`.

### `ingredients.js`

`FA.ING` — массив записей:

```js
[id, "Название", "Latin name", "категория", [сладость, кислота, горечь, соль, умами, жар, аромат], цена, "сезон", "теги", "заметка"]
```

* вкус — целые числа `0–3`;
* цена — `1` эконом, `2` средний, `3` премиум;
* сезон — `весна`, `лето`, `осень`, `зима` или `круглый год`;
* теги — строка через запятую (используется поиском).

### `pairs.js`

`FA.PAIRS` — объект «якорь → список партнёров»:

```js
tomato: "basil:3:cl mozzarella:3:cl olive_oil:3:af ..."
```

Формат токена: `id:вес:код`. Вес `3` — классика, `2` — уверенно, `1` — смело.
Код — причина из `FA.REASONS` (`cl`, `ar`, `af`, `ss`, `ct`, `rg`, `um`, `ht`, `sw`, `fr`, `sm`).
Связи симметричны: достаточно указать пару один раз, дубликаты схлопываются по максимальному весу.

### `trios.js`

`FA.TRIOS` — 69 объектов `{ ids, name, note, tags, price, season }`.
`price` пересчитывается при загрузке как цена самого дорогого компонента — так же,
как у трио, которые собирает генератор.

### `meta.js`

`FA.CATS` (12 категорий), `FA.REASONS` (коды причин), `FA.WHY` (объяснения для
конкретных пар), `FA.PRINCIPLES`, `FA.SOURCES`.

## Как добавить пару

1. Убедитесь, что оба ингредиента есть в `ingredients.js`.
2. Добавьте токен в `pairs.js` в любую из двух строк (симметрия схлопнется).
3. Выберите вес и код причины.
4. Обновите страницу — атлас, карточки и генератор подхватят связь сами.

## Принципы и границы

Сочетания собраны по кулинарной традиции, ароматической химии и практике:
The Flavor Bible, The Flavour Thesaurus, On Food and Cooking, The Oxford Companion
to Food, foodpairing.com, Serious Eats, Larousse Gastronomique.

Это кураторская модель, а не лабораторные измерения. Вес связи — оценка
уверенности, а не физическая величина. Аллергии и диеты не учитываются.
