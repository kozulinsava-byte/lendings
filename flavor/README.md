# Вкусовой атлас

Сайт о сочетаниях вкусов: 173 продукта, 3 801 проверенная пара, генератор
сочетаний на 2–4 компонента и 69 готовых трио. Каждое сочетание показывается
фотографиями продуктов и коротким объяснением, почему оно работает.

Живая версия: <https://kozulinsava-byte.github.io/lendings/flavor/>

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | герой с двумя кнопками, карточка сочетания, витрины атласа и трио |
| `atlas.html` | все 173 продукта: поиск, категории, карточка продукта в диалоге |
| `combos.html` | 69 готовых трио с фотографиями и объяснением |
| `method.html` | принципы базы, источники, лицензии фотографий, ограничения |
| `ingredient.html` | редирект на `atlas.html?id=…` (старые ссылки) |

Сборки нет: чистый HTML + CSS + JS, открывается как есть.

## Как это устроено

* `index.html` — единственное место, где живёт генератор: кнопка «Рандомное
  сочетание» и диалог «Сочетание с настройками» (сколько продуктов, бюджет,
  что исключить). Результат всегда один и тот же блок: фотографии, название,
  объяснение и идея приготовления.
* Ссылку на сочетание можно скопировать: оно кодируется в `?c=tomato,basil,…`.
* `assets/app.js` — вся логика; `assets/style.css` — оформление.

## Данные

Обычные JS-файлы в `assets/data/`, подключаются до `app.js`.

### `ingredients.js`

`FA.ING` — массив записей:

```js
[id, "Название", "Latin name", "категория", [сладость, кислота, горечь, соль, умами, жар, аромат], цена, "сезон", "теги", "заметка"]
```

* вкус — целые числа `0–3`;
* цена — `1` эконом, `2` средний, `3` премиум;
* теги — строка через запятую (используется поиском).

### `pairs.js`

`FA.PAIRS` — объект «якорь → список партнёров», токен `id:вес:код`.
Вес `3` — классика, `2` — уверенно, `1` — смело. Код — причина из `FA.REASONS`.
Связи симметричны: достаточно указать пару один раз.

### `trios.js`

`FA.TRIOS` — 69 объектов `{ ids, name, note, tags, price, season }`.

### `meta.js`

`FA.CATS`, `FA.REASONS`, `FA.WHY` (объяснения конкретных пар), `FA.PRINCIPLES`,
`FA.SOURCES`.

## Фотографии

`assets/img/ing/<id>.jpg` — квадратные кропы 640×640 из Wikimedia Commons
(CC0, CC BY, CC BY-SA). Соответствие «продукт → файл → лицензия → автор»
лежит в `assets/img/manifest.json` и выводится на странице «О данных».

Порядок замены фото: положить новый файл с тем же именем — сайт подхватит.
Если картинки нет, плитка покажет первую букву названия, вёрстка не поедет.

## Как добавить пару

1. Убедись, что оба ингредиента есть в `ingredients.js`.
2. Добавь токен в `pairs.js` в любую из двух строк.
3. Обнови страницу — атлас, карточки и генератор подхватят связь сами.

## Принципы и границы

Сочетания собраны по кулинарной традиции, ароматической химии и практике:
The Flavor Bible, The Flavour Thesaurus, On Food and Cooking, The Oxford
Companion to Food, foodpairing.com, Serious Eats, Larousse Gastronomique.

Это кураторская модель, а не лабораторные измерения. Вес связи — оценка
уверенности, а не физическая величина. Аллергии и диеты не учитываются.
