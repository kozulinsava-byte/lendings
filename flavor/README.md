# Вкусовой атлас

Сайт о сочетаниях вкусов: 173 продукта, 3 801 проверенная пара, генератор
сочетаний на 2–4 компонента и 69 готовых трио. На главной — две кнопки:
случайное сочетание и сочетание с настройками. К каждому сочетанию всегда
показываются фотографии продуктов и короткое объяснение.

Живая версия: <https://kozulinsava-byte.github.io/lendings/flavor/>

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | главный экран: две кнопки, настройки, карточка сочетания |
| `atlas.html` | все 173 продукта: поиск, категории, карточка в диалоге |
| `combos.html` | 69 готовых трио с фотографиями и объяснением |
| `method.html` | принципы базы, источники, лицензии фотографий |
| `ingredient.html` | редирект на `atlas.html?id=…` (старые ссылки) |

Сборки нет: чистый HTML + CSS + JS.

## Как устроен главный экран

* Два состояния в одном документе: «старт» (заголовок и две кнопки) и
  «настройки» (сколько продуктов, бюджет, что исключить). Переключаются
  кнопками, без модальных окон.
* Под кнопками — карточка сочетания: фотографии, название, короткое
  описание и кнопка «Ещё сочетание». Она есть всегда, поэтому экран
  не бывает пустым.
* Сочетание кодируется в ссылке: `?c=tomato,basil,mozzarella`. Настройки
  открываются параметром `?view=settings`.

## Данные

Обычные JS-файлы в `assets/data/`, подключаются до `app.js`.

### `ingredients.js`

`FA.ING` — массив записей:

```js
[id, "Название", "Latin name", "категория", [сладость, кислота, горечь, соль, умами, жар, аромат], цена, "сезон", "теги", "заметка"]
```

* вкус — целые числа `0–3`;
* цена — `1` эконом, `2` средний, `3` премиум;
* теги — строка через запятую.

### `pairs.js`

`FA.PAIRS` — «якорь → партнёры», токен `id:вес:код`. Вес `3` — классика,
`2` — уверенно, `1` — смело; код — причина из `FA.REASONS`. Связи симметричны.

### `trios.js`

`FA.TRIOS` — 69 объектов `{ ids, name, note, tags, price, season }`.
Если сочетание совпало с готовым трио, описание берётся из его `note`.

### `meta.js`

`FA.CATS`, `FA.REASONS`, `FA.WHY` (объяснения пар), `FA.PRINCIPLES`, `FA.SOURCES`.

## Фотографии

`assets/img/ing/<id>.jpg` — квадратные кропы 640×640 из Wikimedia Commons
(CC0, CC BY, CC BY-SA). Соответствие «продукт → файл → лицензия → автор» —
в `assets/img/manifest.json`, список выводится на странице «О данных».

Нет картинки — плитка покажет первую букву названия, вёрстка не поедет.

## Как добавить пару

1. Оба ингредиента есть в `ingredients.js`.
2. Добавить токен в `pairs.js` в любую из двух строк.
3. Обновить страницу — атлас, карточки и генератор подхватят связь сами.

## Принципы и границы

Сочетания собраны по кулинарной традиции, ароматической химии и практике:
The Flavor Bible, The Flavour Thesaurus, On Food and Cooking, The Oxford
Companion to Food, foodpairing.com, Serious Eats, Larousse Gastronomique.

Это кураторская модель, а не лабораторные измерения. Вес связи — оценка
уверенности, а не физическая величина. Аллергии и диеты не учитываются.
